Código ZPL

O PDF não precisa virar ZPL: cada etiqueta é desenhada direto no tamanho do formato escolhido, sem distorcer, e vai para a impressora exatamente como aparece na prévia.

    Novo formato

    Só vale para PDF: afasta o desenho da beira da etiqueta, onde a térmica falha quando o rolo avança um pouco torto. O ZPL não usa — ele já diz onde cada coisa vai.

    É assim que o Mercado Livre entrega a etiqueta de duas vias: um arquivo só, com a segunda coluna desenhada mais à direita. Marcado, o programa desenha a folha inteira e não monta par nenhum — o arquivo já vem montado.

    Adicionar imagem à etiqueta

    A imagem entra no ZPL como ^GF comprimido — a etiqueta continua sendo um arquivo de texto.
